# Google 試算表設定步驟

大約 10 分鐘，只需要做一次。

## 1. 建立試算表
1. 打開 https://sheets.new，會開一份新的空白試算表。
2. 左上角把名稱改成「楓藝諮詢紀錄」。

## 2. 貼上程式
1. 上方選單點「擴充功能」→「Apps Script」，會開一個新分頁。
2. 把編輯器裡原本的內容全部刪掉。
3. 把 `apps-script/Code.gs` 的內容全部複製、貼上。
4. 按上方的 💾（儲存）。

## 3. 執行一次 setup
1. 上方工具列的下拉選單選「setup」，按「▶ 執行」。
2. 第一次會跳出「需要授權」：
   1. 按「審查權限」，選你的 Google 帳號。
   2. 如果出現「Google 尚未驗證這個應用程式」，按左下「進階」→「前往（不安全）」。這是你自己寫的程式，所以這樣是正常的。
   3. 按「允許」。
3. 下方「執行記錄」會出現一行**後台網址**，把它複製下來：
   - 加入你的瀏覽器書籤
   - 不要傳給別人，也不要貼到對話裡
4. 回到試算表，會多一個「諮詢」工作表，第一列是欄位名稱。

## 4. 設定通知信箱（有信箱之後再做）
1. Apps Script 左側點 ⚙️「專案設定」。
2. 捲到最下面的「指令碼屬性」，按「新增指令碼屬性」：
   - 屬性：`NOTIFY_EMAIL`
   - 值：你要收通知的 Email
3. 按「儲存指令碼屬性」。
4. 要測試的話，回編輯器選「testNotify」，按「▶ 執行」，然後去收信。

## 5. 部署成網頁應用程式
1. 右上角「部署」→「新增部署作業」。
2. 點左邊齒輪 ⚙️，選「網頁應用程式」。
3. 設定：
   - 說明：楓藝諮詢
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，把「網頁應用程式」的網址（`https://script.google.com/macros/s/…/exec`）複製給我。這個網址可以公開，沒有秘密碼的人只能送出表單，看不到任何資料。

## 之後如果要改程式
改完後要按「部署」→「管理部署作業」→ 鉛筆圖示 → 版本選「新版本」→「部署」。這樣網址不會變，新程式才會生效。

## 後台網址外流了怎麼辦
在編輯器選「rotateKey」，按「▶ 執行」。執行記錄會出現新的後台網址，舊網址立刻失效，記得更新書籤。

## 改成好記的秘密碼（例如首頁網址加 #yizhan）
1. Apps Script 左側 ⚙️「專案設定」→「指令碼屬性」。
2. 找到 `ADMIN_KEY`，按「編輯」，把值改成你要的字（只用英文字母和數字），按「儲存指令碼屬性」。
3. 之後打開 `首頁網址/#你的秘密碼` 就會進到後台。
4. 秘密碼越短越好猜。程式已經設定成 10 分鐘內猜錯 30 次就暫時全部擋掉，但還是建議不要用太常見的字。
